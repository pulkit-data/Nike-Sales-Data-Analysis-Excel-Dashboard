# Nike Sales Data Analysis – Excel Dashboard

## Project Overview
This project involves cleaning a messy sales dataset and building an interactive dashboard using **Microsoft Excel** (Power Query, Pivot Tables, Charts, and Slicers).

The objective was to transform dirty data into clear business insights through an interactive dashboard.

---

## Tools Used
- Microsoft Excel
  - Power Query (Data Cleaning)
  - Pivot Tables
  - Charts
  - Slicers

---

## Dataset
- **Source**: [Nike Sales Uncleaned Dataset (Kaggle)](https://www.kaggle.com/datasets/nayakganesh007/nike-sales-uncleaned-dataset)
- Common data quality issues handled: missing values, negative values, inconsistent Size column, and incorrect data types.

---

## Key Insights

- Kolkata generated the highest revenue among all cities (₹1.65 Lakhs).
- Online channel slightly outperformed Retail (₹4 Lakhs vs ₹3.86 Lakhs).
- Flex Trainer emerged as the top-performing product by revenue.
- Men contributed the highest overall revenue (approximately ₹3.1 Lakhs), significantly higher than Women and Kids.

---

## Recommendation

Prioritize digital marketing campaigns for **Women’s Lifestyle** products in the Online channel. Although this category currently has limited Online presence, its strong performance in Retail indicates clear untapped potential.
